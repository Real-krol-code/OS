**Задание 1** 
Необходимо написать программу, которая производит подбор строки по заданному хешу и параметрам
Релизация данной задачи представлена в файле brute-force.c.
Для запуска программы необходимо:
1) скомпилировать и сохранить результат код командой gcc brute-force -lcrypt -o brute
2) Сгкнкрируем хэш для примера: openssl passwd -6 -salt test ab
3) Запустим программу с заданными параметрами:
./brute -a abcd -n 2 -h 'получившийся хэш с прошлого запроса' -s '$6$test$'
4) выводиться ответ.
